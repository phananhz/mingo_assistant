# Source Layout

```text
app/          Khởi động ứng dụng và điều phối lifecycle
config/       Cấu hình ứng dụng
core/         Thành phần dùng chung
database/     SQLite, migration, seed
models/       Entity/domain model
repositories/ Truy cập dữ liệu
services/     Nghiệp vụ OCR, template, validation, export
ui/           Giao diện PySide6
workers/      Tác vụ nền
utils/        Tiện ích kỹ thuật
```
